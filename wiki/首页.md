## 快速导航

| 概念 | 说明 |
|------|------|
| **末日轮盘** | 末日降临后出现在世界各地的巨大转盘，可消耗魔晶进行抽奖，是获取力量的唯一途径 |
| **魔晶** | 击杀怪物获得的晶体，分为不同等级/颜色，是末日后世界的核心货币 |
| **强化人/进化者** | 通过强化药剂提升身体能力的人类，分为不同等阶 |
| **职业者** | 通过职业证书获得特殊技能的人类，拥有超越常人的战斗能力 |
| **变异兽** | 末日降临后被感染的动物，体型巨大化并具有特殊能力 |
| **变异植物** | 被末日力量感染的植物，具有攻击性和特殊能力 |
