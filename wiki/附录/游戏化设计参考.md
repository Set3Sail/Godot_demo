# 附录 · 游戏化设计参考

> 基于《轮盘世界》世界观设计开放世界RPG游戏的核心参考。

---

## 一、游戏核心循环

```
探索世界 → 猎杀怪物 → 获取魔晶 → 转动轮盘(抽卡/抽奖)
    ↑                                        ↓
    │                                    获取奖励
    │                                        ↓
    └────────── 变强后挑战更难内容 ←──── 进化/装备/技能提升
```

---

## 二、核心系统设计建议

### 2.1 轮盘抽奖系统
```
设计要点:
- 多个等级轮盘分布在世界各地
- 消耗魔晶（货币）抽奖
- 随机奖励池（类似gacha）
- 稀有轮盘有使用限制/占领机制
- 彩色轮盘 = SSR/UR级奖励（职业解锁）
```

### 2.2 魔晶货币系统
```
击杀怪物 → 获得魔晶
         ↓
用途: 转轮盘 / 交易 / 锻造材料 / 强化装备
         ↓
不同颜色魔晶 = 不同价值层级
         ↓
高阶魔晶极难获取 → 驱动玩家挑战高难内容
```

### 2.3 进化者等级系统
```
玩家等级 = 星阶进化者
  一星 → 二星 → ... → 十星
  每星突破需要: 对应进化药剂
  进化药剂来源: 轮盘抽奖 / 高级制作 / 副本BOSS掉落
```

### 2.4 职业系统
```
分为两大分支:
  战斗职业 (战士/枪手/法师/召唤师/刺客...)
  辅助职业 (锻造师/药师/附魔师/厨师...)

获取方式: 彩色轮盘抽出职业证书
职业等级: 见习 → 初级 → 中级 → 高级 → 大师 → 宗师 → 传说
升级方式: 熟练度积累 + 进阶试炼任务
```

## 三、开放世界设计

### 3.1 区域分级
| 区域 | 怪物等级 | 轮盘等级 | 推荐玩家等级 |
|------|----------|----------|-------------|
| 新手城市区 | 一级丧尸 | 一级轮盘 | 普通人→一星 |
| 郊外荒地 | 变异虫/植物 | 二级轮盘 | 一星→二星 |
| 废弃城区 | 二级丧尸/变异兽 | 三级轮盘 | 二星→三星 |
| 秘境（白/绿） | 守护兽/高级怪物 | 彩色轮盘 | 三星→五星 |
| 秘境（蓝/红） | 地狱兽/异形 | 高级轮盘 | 五星→七星 |
| 圣城区域 | 顶级怪物/敌对势力 | 顶级轮盘 | 七星→九星 |
| 秘境（黑） | 准神级怪物 | 传说轮盘 | 九星→十星 |

### 3.2 动态事件
- **兽潮**：周期性大规模怪物攻城
- **聚宝盆**：稀有事件，召唤BOSS但奖励丰厚
- **势力战争**：NPC势力间的冲突，玩家可选边
- **轮盘刷新**：限时彩色轮盘出现

## 四、战斗系统

### 4.1 基础战斗
- 动作向/半动作向
- 近战+远程+技能
- 弱点系统（头部、魔晶位置等）
- 闪避/格挡/受身

### 4.2 职业技能系统
- 每个职业3-5个主动技能
- 精神力/魔力资源管理
- 技能升级树
- 双职业切换（参考叶默）

### 4.3 战兽系统
- 可驯服变异兽为战兽
- 战兽有独立成长线
- 战斗中可召唤/指挥
- 主人与战兽协同技能

## 五、经济系统

### 5.1 货币层级
```
一级魔晶 (白) — 基础货币
二级魔晶 (灰) — 中级货币
三级魔晶 (绿) — 高级货币
四级魔晶 (蓝) → 持续升级
```

### 5.2 轮盘经济
```
玩家获取魔晶 → 选择轮盘消费 → 随机获得奖励
                                   ↓
                          自用 / 交易给其他玩家(NPC)
```

### 5.3 制作经济
```
收集材料(打怪+采集) → 锻造/制药/附魔 → 产出装备/消耗品 → 交易
```

## 六、剧情适配

### 6.1 主线任务
1. 末日降临 → 初次使用轮盘
2. 获取第一个职业
3. 建立/加入营地
4. 第一次兽潮防御
5. 探索第一个秘境
6. 与各势力建立关系
7. 圣城远征（最终主线）
8. 天界之路（终局内容/扩展DLC）

### 6.2 支线任务
- 队友角色任务线
- 势力声望任务
- 秘境探索任务
- 稀有轮盘线索任务
- 传奇装备制作任务

---

## 七、社交与多人

### 7.1 可选模式
- **单人模式**：扮演叶默，体验原著剧情
- **联机合作**：多人组队探索秘境、对抗兽潮
- **势力战**：玩家加入不同势力进行PVP

### 7.2 角色自定义
- 创建原创角色（非叶默）
- 选择初始职业路线
- 通过轮盘获取随机职业/技能（Roguelike元素）
- 在同一世界观下书写自己的故事

---

## 八、核心设计哲学

1. **轮盘 = 核心驱动力**：一切围绕"打怪→获得魔晶→转轮盘→变强"循环
2. **随机性 = 重玩价值**：轮盘的完全随机性带来每局不同的体验
3. **职业多样性 = 玩法深度**：战斗+辅助双职业体系提供丰富的Build空间
4. **势力博弈 = 世界活力**：动态的势力关系让世界有生命力
5. **渐进式揭秘 = 叙事张力**：从末日生存到天界真相的层层递进
