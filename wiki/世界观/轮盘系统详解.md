# 世界观 · 轮盘系统详解

> 末日轮盘是《轮盘世界》最核心的设定，是末日力量的来源和人类生存的根基。

---

## 一、轮盘的起源

- **出现时间**：2220年9月10日16:40，与末日降临同时
- **出现方式**：从天空坠落，随机散布在世界各地
- **本质**：由超越人类认知的高等存在制造/投放的力量分配装置
- **幕后**：天界/上级空间的操纵者通过轮盘控制地球人类的进化进程

---

## 二、轮盘等级体系

### 2.1 一级轮盘
```
┌─────────────────────┐
│  镶嵌黄色水晶宝石      │
│  1个魔晶槽位          │
│  (稀有版: 7+槽位)     │
│  10个奖励分区         │
│  指针: 黑色/红色       │
└─────────────────────┘
```
- **转一次消耗**：1枚一级魔晶
- **常见奖励**：一级进化药剂、弩、食物、水、医药箱、简单武器
- **稀有奖励**：一级进化药剂（最佳单次奖励）
- **分布**：最常见，几乎每个区域都有

### 2.2 二级轮盘
- **转一次消耗**：10枚一级魔晶（或等值更高级魔晶）
- **奖励池**：一级进化药剂、不完全免疫药剂、臂盾（灰色品质白色装备）、更高级武器
- **出现位置**：特定地点（如学校体育馆）

### 2.3 三级轮盘
- **转一次消耗**：100枚一级魔晶
- **奖励池**：更高级药剂、职业相关物品、高品质装备

### 2.4 彩色轮盘
```
彩色轮盘分为:
  三彩轮盘 (3色)
  五彩轮盘 (5色)
  七彩轮盘 (7色)  ← 最常见的高级轮盘
  九彩轮盘 (9色)
  
注意: 不存在偶色彩轮盘 (4/6/8彩)
```
- **特点**：
  - 唯一可转出**职业证书**和**契约皮卷**的轮盘
  - 存在时间限制（数分钟至十分钟）
  - 黑色区域 = 轮空（转盘可能爆炸，直接杀死使用者！）
  - 投入魔晶需达到能量总和要求（低级魔晶也可，只要总量够）
- **风险**：如在时限内未满足能量要求，之前投入的魔晶全部损失

### 2.5 九级十层轮盘
- **转一次消耗**：海量顶级魔晶
- **顶级奖励**：金色圣光战甲、传说级装备、超级技能卡等

### 2.6 特殊轮盘类型
| 类型 | 说明 |
|------|------|
| 微型轮盘 | 可携带，8格选项（4奖励4惩罚），需1枚高级魔晶 |
| 母巢轮盘 | 大型怪物身上的轮盘，可转出通往对应空间的钥匙 |
| 职业轮盘 | 专门产出职业相关物品 |

## 三、轮盘使用机制

### 3.1 基本流程
```
1. 将魔晶投入槽位
   ↓
2. 红色指针开始旋转
   ↓
3. 指针在奖励图标间快速切换
   ↓
4. 指针停止 → 指向的图标 = 获得奖励
   ↓
5. 奖励物品出现在下方奖励台
```

### 3.2 关键规则
- **无限使用**：只要投币就能无限次旋转
- **完全随机**：没有任何规律或保底机制
- **独立运作**：每个轮盘有独立的奖励池
- **多人共用**：多个幸存者可轮流使用同一轮盘

### 3.3 多层轮盘机制
部分高级轮盘为多层结构：
```
   第三层奖励（最佳）
  ┌──────────┐
  │ 第二层奖励 │
  │ ┌──────┐ │
  │ │第一层  │ │
  │ │奖励   │ │
  │ └──────┘ │
  └──────────┘
```
- 每层单独转动
- 全部层转动后，奖励合并
- 最终可能获得远超单层的超级大奖

## 四、轮盘奖励池

### 4.1 消耗品类
- 各类进化药剂（一星至九星）
- 免疫药剂（不完全/完全）
- 精神力药水（蓝瓶）
- 治疗药水
- 食物和净水

### 4.2 装备类
- 武器（弩、手枪、砍刀、战刃等）
- 防具（臂盾、护甲、棉袍等）
- 饰品（各类戒指、项链等）
- 特殊装备（空间水壶等）

### 4.3 技能/能力类
- 功能卡（夜视、石肤、感知等）
- 职业证书 + 契约皮卷
- 技能卷轴
- 武技秘籍

### 4.4 特殊类
- 血脉物品
- 宠物/战兽蛋
- 秘境钥匙
- 图纸/配方
- 折扣卡

## 五、轮盘的占领与经济

### 5.1 轮盘占领
- 强者或势力会占领优质轮盘
- 设置关卡，向外来者收取"使用费"
- 末日后最珍贵的战略资源

### 5.2 轮盘经济
```
幸存者猎杀怪物 → 获得魔晶 → 支付轮盘使用费 → 转动轮盘 → 获得力量 → 猎杀更强怪物
                                                    ↓
                                              多余奖励 → 交易市场 → 换取魔晶/其他物资
```

---

## 六、轮盘的隐藏真相

### 6.1 幕后操控
- 轮盘并非自然产生的神奇物品
- 由天界/上级空间的高等存在设计
- 目的是筛选和培养强者

### 6.2 进化陷阱？
- 轮盘让人类变强 → 变强后达到九星 → 被强制传送到上级空间 → 成为"战场"上的棋子
- 暗示整个地球末日可能是更高层次存在的实验/游戏

### 6.3 最终的轮盘
- 母巢轮盘可转出通往上级空间的钥匙
- 暗示轮盘体系与整个多元宇宙连通
