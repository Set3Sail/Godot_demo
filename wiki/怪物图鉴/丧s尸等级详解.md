# 怪物图鉴 · 丧尸等级详解

> 丧尸是末日中最常见也最基础的怪物类型。本章节详细阐述丧尸的分类、等级、能力与应对策略。

---

## 一、丧尸的诞生

### 感染机制
```
末日光线照射死亡 → 转化为丧尸 (初代)
       OR
被丧尸抓伤/咬伤 → 30分钟内感染 → 转化为丧尸
```

### 基础特征（普通丧尸）
| 特征 | 描述 |
|------|------|
| **皮肤** | 灰黑色，布满暗红色/青紫色血管 |
| **眼睛** | 血红色，无瞳孔感 |
| **口部** | 长有尖牙，流出黏稠黑色液体 |
| **手指** | 长出墨绿色尖指甲 |
| **头发** | 稀疏脱落 |
| **智力** | 完全丧失，只剩嗜血本能 |
| **感官** | 视觉(动态敏感)、听觉(声敏)、嗅觉(活人气味) |
| **弱点** | 头部是唯一致命要害 |
| **力量** | 约1.5-3倍普通人 |
| **速度** | 普通丧尸速度不快 |

## 二、等级体系

### 2.1 一级丧尸 (普通丧尸)
```
魔晶: 白色一级
力量: 约1.5-3倍普通人
速度: 慢（初期）
智力: 无（本能驱动）
威胁: ★☆☆☆☆ (对强化人)
      ★★★★☆ (对普通人)
```
- 最常见的类型
- 单体威胁低，群体威胁高
- 在城市区域密集分布

### 2.2 二级丧尸
```
魔晶: 灰色/白色二级
力量: 明显提升
速度: 显著加快
防御: 皮肤开始硬化
智力: 极低（有些许狩猎本能）
威胁: ★★☆☆☆
```

### 2.3 三级丧尸 (铁臂丧尸)
```
魔晶: 绿色三级
特征: 一只手臂变异为粗大黑色巨臂
力量: 极高的局部力量
速度: 中等
防御: 身体部位显著强化
智力: 初级狩猎本能
威胁: ★★★☆☆
特殊: 巨臂可轻易撕碎木门和薄墙
```

### 2.4 四级丧尸
```
魔晶: 蓝色四级
特征: 已恢复部分智慧
能力: 懂得伏击和基础战术
速度: 全方位提升
威胁: ★★★★☆
特殊: 可能拥有基础天赋技能
```

### 2.5 五级丧尸及以上
```
魔晶: 紫色五级 → 橙色六级 → 金色七级 → 彩色八级 → 黑色九级
智力: 逐渐恢复，高阶接近人类
能力: 各种天赋技能
威胁: ★★★★★ 以上
```

### 2.6 特殊变种

| 类型 | 特征 | 威胁 |
|------|------|------|
| **尸童** | 儿童丧尸，速度极快、狡猾 | ★★★★ |
| **喷毒丧尸** | 可喷射腐蚀性毒液 | ★★★★ |
| **巨型头颅丧尸** | 可从口中射出触须/钩子吸取血肉 | ★★★★★ |
| **尸猿** | 猿类丧尸，进化速度远超地面丧尸 | ★★★★★+ |

## 三、丧尸的再生能力

### 核心规则
> 只要头部完整且魔晶未被取出，丧尸可以通过吞噬血肉**再生完整身体**！

### 机制
```
只剩头部的丧尸
    ↓
吞噬足够血肉
    ↓
一段时间后
    ↓
生长出全新身体（四肢+躯干）
```

### 游戏设计应用
- 击杀丧尸后必须取出魔晶才算彻底消灭
- 如果只是砍掉头部但未取出魔晶 → 它可能被其他丧尸"喂养"后复活
- 增加了末日世界的持续性威胁感

## 四、丧尸行为模式

### 4.1 日常行为
- **徘徊**：无目标时缓慢游荡
- **聚集**：向声源、光源、活人气息方向聚集
- **进食**：发现活人/新鲜尸体时疯狂进食
- **转化**：感染新的人类成为同类

### 4.2 群体行为
- **丧尸潮**：数百至数万丧尸同时向某个方向移动
- **触发机制**：爆炸声、大规模战斗、兽潮等
- **危险性**：即使高级进化者也难以从丧尸潮中全身而退

### 4.3 昼夜差异
- **白天**：活动性相对较低
- **夜晚**：活跃度增加，危险性大幅提升
- 高级丧尸没有明显的昼夜差异

## 五、应对策略

### 5.1 对普通人
| 策略 | 说明 |
|------|------|
| 避开 | 最安全的选择 |
| 安静 | 不制造声响 |
| 遮挡气味 | 用丧尸血肉涂抹自身 |
| 高处 | 丧尸不会攀爬 |
| 火攻 | 丧尸怕火 |

### 5.2 对进化者
| 等级 | 推荐策略 |
|------|----------|
| 一星进化者 | 可单挑数只普通丧尸，但需避免被包围 |
| 二星进化者 | 可清剿普通丧尸群，对二级丧尸需注意 |
| 三星+进化者 | 普通丧尸不再是威胁，但需注意特殊变种 |

### 5.3 对高阶丧尸
- 需团队配合
- 针对其天赋技能的弱点
- 高级装备和技能卡的价值体现

## 六、魔晶获取

### 从丧尸取魔晶
```
1. 确认丧尸完全死亡（头部破坏）
2. 使用刀具在头部寻找魔晶
3. 魔晶通常嵌在脑部中央位置
4. 小心取出，避免损坏
```
