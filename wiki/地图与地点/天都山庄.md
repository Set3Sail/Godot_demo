# 地图与地点 · 天都山庄

> 叶默创立的末日后最强幸存者基地，从一个别墅区发展为超级军事要塞。

---

## 基本信息

| 属性 | 内容 |
|------|------|
| **名称** | 天都山庄（天湖别苑 → 天都山庄 → 天都基地） |
| **创始人** | 叶默 |
| **建立时间** | 末日降临后数日内 |
| **定位** | 末日后最强幸存者势力的大本营 |
| **人口** | 核心战士数千人 + 大量平民 |

---

## 发展历程

### 第一阶段：据点建立（末日初期）
```
原址: 天湖别苑（高档小区）
    ↓
清理周边丧尸和变异生物
    ↓
利用别墅区作为初始营地
    ↓
园丁职业控制变异植物作为"天然屏障"
```

### 第二阶段：堡垒化（末日数周-数月）
```
建立城墙防御系统
    ↓
建设锻造工坊（生产装备）
    ↓
建设药剂工坊（生产进化药剂）
    ↓
吸引幸存者投靠
```

### 第三阶段：超级要塞（末日数月-数年）
```
扩大领地范围
    ↓
建立完整的军事体系
    ↓
控制周边城市（如英雄城）
    ↓
成为超一流势力
```

## 核心设施

### 锻造工坊
- **功能**：生产武器、装备、弹药
- **负责人**：叶默（荣耀工匠）
- **产出**：白色至蓝色品质装备
- **特色**：可对现有装备进行附魔和升级

### 药剂工坊
- **功能**：生产进化药剂、免疫药剂、治疗药剂
- **原料**：变异植物、魔晶、化学药品
- **产出**：各等级进化药剂

### 城墙防御系统
- **结构**：多层防御工事
- **武器**：弩炮、枪械、元素攻击点
- **补充**：变异植物构成的天然防御带

### 交易市场
- **类型**：基地内部市场
- **交易物品**：魔晶、装备、药剂、食物、材料
- **货币**：以魔晶为基础的信用体系

## 军事力量

### 核心战力（十星级）
- 叶默（领主）
- 墨夜（冰系法师）
- 其他十星进化者数名
- 地皇犬（十星战兽）
- 黑猫（十星战兽）

### 军队编制
- 正式编制战士数千人
- 分多个战团
- 配备标准化装备（天都山庄锻造）

### 防御特点
- 变异植物构成第一道防线
- 城墙和防御工事为第二道防线
- 进化者部队为机动防御力量
- 战兽用于巡逻和预警

## 战略意义

1. **轮盘控制**：周边多个轮盘在天都控制之下
2. **物资生产**：自给自足的装备和药剂生产能力
3. **人才聚集**：最强进化者和职业者的汇聚地
4. **贸易中心**：与多方势力保持交易关系
5. **军事威慑**：能远征灭掉圣城的军事力量
