世界观 · 概述

本章节详细阐述《轮盘世界》的核心世界观设定，包括末日起因、轮盘体系、力量层级、职业系统、世界规则等。

一、末日降临

1.1 末日开端

  • 时间：2220年9月10日 16:40
  • 事件：一场毁灭性的灾难突然降临地球
  • 表现：
  • 天空出现巨大蘑菇云般的爆炸
  • 一艘金色圣光战甲（九级十层轮盘顶级奖励之一）出现在天际
  • 大量人类在灾难中死亡，随后转化为丧尸
  • 地球上的动植物发生恐怖变异
  • 末日轮盘在世界各地随机出现

1.2 末日成因

  • 天空中的战争：高等级存在之间的战斗导致末日开始
  • 巨大的"根"状物从天空延伸至地面，释放怪物
  • 金色圣光战甲的出现暗示有超越人类认知的战争在进行
  • 最终揭示：末日背后存在上层世界/天界的幕后操纵者

1.3 末日影响

  • 人口锐减：大量人类在灾难和丧尸潮中死亡
  • 环境剧变：动植物大规模变异，生态环境彻底改变
  • 社会崩塌：原有秩序崩溃，幸存者形成新势力
  • 人类进化：幸存者通过轮盘获得力量，成为进化者
  • 秘境出现：特殊区域随末日降临而出现，充满危险与机遇

二、轮盘体系

2.1 轮盘概述

末日轮盘是末日后世界最核心的存在。它是一个巨大的转盘装置，散落在世界各地。幸存者消耗魔晶来转动轮盘，随机获得奖励。

2.2 轮盘等级

等级 标识 魔晶槽位 稀有度 说明
一道轮盘 黄色水晶宝石 1个（普通）/ 多个（稀有） 最常见 分布最广
二道轮盘 橘色/红色宝石 10个 较稀有 奖励品质提升

九级十层轮盘 金色圣光 — 传说级 最强装备来源

2.3 轮盘结构

  • 底座：巨大的圆形底座，镶嵌对应等级的宝石
  • 指针：黑色/红色指针，指向奖励区域
  • 槽位：投入魔晶的凹槽，数量决定轮盘等级
  • 面板：显示可获得的奖励图标
  • 奖励台：获奖物品出现的位置

2.4 使用规则

  1. 投入魔晶至槽位
  2. 指针在奖励图标间旋转
  3. 指针停止时指向的图标即为奖励
  4. 奖励从奖励台中出现
  5. 可无限次使用
  6. 多层轮盘需逐层转动，层层叠加可获最终大奖

2.5 轮盘特性

  • 随机性：奖励完全随机
  • 独立性：每个轮盘奖励池不同
  • 占据性：强者占据优质轮盘，收取"使用费"
  • 多样性：不同位置轮盘奖励倾向不同
  • 进化性：末日推进可能带来轮盘进化

世界观 · 轮盘系统详解

末日轮盘是《轮盘世界》最核心的设定，是末日力量的来源和人类生存的根基。

一、轮盘的起源

  • 出现时间：2220年9月10日16:40，与末日降临同时
  • 出现方式：从天空坠落，随机散布在世界各地
  • 本质：由超越人类认知的高等存在制造/投放的力量分配装置
  • 幕后：天界/上级空间的操纵者通过轮盘控制地球人类的进化进程

二、轮盘等级体系

2.1 一级轮盘

┌─────────────────────┐
│  镶嵌黄色水晶宝石      │
│  1个魔晶槽位          │
│  (稀有版: 7+槽位)     │
│  10个奖励分区         │
│  指针: 黑色/红色       │
└─────────────────────┘
  • 转一次消耗：1枚一级魔晶
  • 常见奖励：一级进化药剂、弩、食物、水、医药箱、简单武器
  • 稀有奖励：一级进化药剂（最佳单次奖励）
  • 分布：最常见，几乎每个区域都有

2.2 二级轮盘

  • 转一次消耗：10枚一级魔晶（或等值更高级魔晶）
  • 奖励池：一级进化药剂、不完全免疫药剂、臂盾（灰色品质白色装备）、更高级武器
  • 出现位置：特定地点（如学校体育馆）

2.3 三级轮盘

  • 转一次消耗：100枚一级魔晶
  • 奖励池：更高级药剂、职业相关物品、高品质装备

2.4 彩色轮盘

彩色轮盘分为:
  三彩轮盘 (3色)
  五彩轮盘 (5色)
  七彩轮盘 (7色)  ← 最常见的高级轮盘
  九彩轮盘 (9色)

注意: 不存在偶色彩轮盘 (4/6/8彩)
  • 特点：
  • 唯一可转出职业证书和契约皮卷的轮盘
  • 存在时间限制（数分钟至十分钟）
  • 黑色区域 = 轮空（转盘可能爆炸，直接杀死使用者！）
  • 投入魔晶需达到能量总和要求（低级魔晶也可，只要总量够）
  • 风险：如在时限内未满足能量要求，之前投入的魔晶全部损失

2.5 九级十层轮盘

  • 转一次消耗：海量顶级魔晶
  • 顶级奖励：金色圣光战甲、传说级装备、超级技能卡等

2.6 特殊轮盘类型

类型 说明
微型轮盘 可携带，8格选项（4奖励4惩罚），需1枚高级魔晶
母巢轮盘 大型怪物身上的轮盘，可转出通往对应空间的钥匙
职业轮盘 专门产出职业相关物品

三、轮盘使用机制

3.1 基本流程

1. 将魔晶投入槽位
   ↓
2. 红色指针开始旋转
   ↓
3. 指针在奖励图标间快速切换
   ↓
4. 指针停止 → 指向的图标 = 获得奖励
   ↓
5. 奖励物品出现在下方奖励台

3.2 关键规则

  • 无限使用：只要投币就能无限次旋转
  • 完全随机：没有任何规律或保底机制
  • 独立运作：每个轮盘有独立的奖励池
  • 多人共用：多个幸存者可轮流使用同一轮盘

3.3 多层轮盘机制

部分高级轮盘为多层结构：

   第三层奖励（最佳）
  ┌──────────┐
  │ 第二层奖励 │
  │ ┌──────┐ │
  │ │第一层  │ │
  │ │奖励   │ │
  │ └──────┘ │
  └──────────┘
  • 每层单独转动
  • 全部层转动后，奖励合并
  • 最终可能获得远超单层的超级大奖

四、轮盘奖励池

4.1 消耗品类

  • 各类进化药剂（一星至九星）
  • 免疫药剂（不完全/完全）
  • 精神力药水（蓝瓶）
  • 治疗药水
  • 食物和净水

4.2 装备类

  • 武器（弩、手枪、砍刀、战刃等）
  • 防具（臂盾、护甲、棉袍等）
  • 饰品（各类戒指、项链等）
  • 特殊装备（空间水壶等）

4.3 技能/能力类

  • 功能卡（夜视、石肤、感知等）
  • 职业证书 + 契约皮卷
  • 技能卷轴
  • 武技秘籍

4.4 特殊类

  • 血脉物品
  • 宠物/战兽蛋
  • 秘境钥匙
  • 图纸/配方
  • 折扣卡

五、轮盘的占领与经济

5.1 轮盘占领

  • 强者或势力会占领优质轮盘
  • 设置关卡，向外来者收取"使用费"
  • 末日后最珍贵的战略资源

5.2 轮盘经济

幸存者猎杀怪物 → 获得魔晶 → 支付轮盘使用费 → 转动轮盘 → 获得力量 → 猎杀更强怪物
                                                    ↓
                                              多余奖励 → 交易市场 → 换取魔晶/其他物资

六、轮盘的隐藏真相

6.1 幕后操控

  • 轮盘并非自然产生的神奇物品
  • 由天界/上级空间的高等存在设计
  • 目的是筛选和培养强者

6.2 进化陷阱？

  • 轮盘让人类变强 → 变强后达到九星 → 被强制传送到上级空间 → 成为"战场"上的棋子
  • 暗示整个地球末日可能是更高层次存在的实验/游戏

6.3 最终的轮盘

  • 母巢轮盘可转出通往上级空间的钥匙
  • 暗示轮盘体系与整个多元宇宙连通

三、丧尸的再生能力

只要头部完整且魔晶未被取出，丧尸可以通过吞噬血肉再生完整身体！

    ↓

    ↓

游戏设计应用

  • 击杀丧尸后必须取出魔晶才算彻底消灭
  • 如果只是砍掉头部但未取出魔晶 → 它可能被其他丧尸"喂养"后复活
  • 增加了末日世界的持续性威胁感

四、丧尸行为模式

4.1 日常行为

  • 徘徊：无目标时缓慢游荡

  • 转化：感染新的人类成为同类

4.2 群体行为

  • 丧尸潮：数百至数万丧尸同时向某个方向移动

4.3 昼夜差异

  • 白天：活动性相对较低
  • 夜晚：活跃度增加，危险性大幅提升
  • 高级丧尸没有明显的昼夜差异

怪物图鉴 · 怪物总览

本章节收录《轮盘世界》中所有怪物类型，包括丧尸、变异兽、变异植物、地狱兽等。

一、怪物体系概述

末日降临后，地球上的生物受到末日力量的影响发生变异。所有怪物的共同特征是在头部生成"魔晶"——末日世界最核心的资源和货币。

怪物等级体系

等级 魔晶颜色 威胁程度 示例
一级 黄色 低（对强化人） 普通丧尸
二级 — 中 进化丧尸、变异虫群
三级+ — 高 变异兽、变异植物
高级 — 极高 地狱兽、远古种

二、丧尸（丧尸）

2.1 普通丧尸

  • 来源：被末日力量感染死亡后转化的人类
  • 外观：
  • 灰黑色皮肤，布满暗红色血管
  • 血红色眼睛
  • 嘴里长出獠牙，流着黏稠液体
  • 手指长出黑色尖指甲
  • 头发稀疏脱落
  • 行为：
  • 失去理智，只剩嗜血本能
  • 以活人为食
  • 对声音和光线敏感
  • 单体力量约是普通人的2-3倍
  • 弱点：
  • 头部是致命弱点
  • 攻击头部可一击败杀
  • 感染机制：
  • 抓伤或咬伤会被感染
  • 感染者会变成同类
  • 无法治愈
  • 再生能力：
  • 只要头部完整且魔晶未被取出
  • 可以通过吞噬血肉再生完整身体

2.2 进化丧尸

  • 末日数天后开始出现
  • 比普通丧尸更强壮、更快速
  • 部分具有特殊能力
  • 魔晶品质更高
  • 难以单独遇到（常聚集在丧尸群中）

2.3 丧尸特征总结

  • 视觉：可看到运动物体
  • 听觉：对声音敏感
  • 嗅觉：可嗅到活人气味
  • 速度：普通速度不快（初期），进化后增加
  • 力量：超过普通成年人
  • 智力：单体极低，群体可能产生简单的协同行为

三、变异虫类（变异昆虫）

3.1 变异黑甲虫（变异甲虫）

  • 外观：
  • 大小如老鼠/猫
  • 黑色甲壳
  • 多足
  • 行为：
  • 群居，成群行动
  • 偏好腐肉和活人血肉
  • 会主动攻击人类
  • 能力：
  • 喷射绿色/墨绿色腐蚀性液体
  • 腐蚀液可溶解木材、金属、人体
  • 甲壳随着成长变硬
  • 成长：
  • 初期甲壳较软，可被普通刀具砍破
  • 随时间推移甲壳变硬
  • 成年后可长到狮子大小
  • 进化后可威胁高级进化者
  • 食用价值：
  • 甲壳下的肉可食用
  • 含有丰富营养
  • 对强化人有额外好处
  • 需烤熟食用

3.2 白蛆虫（白化巨蛆/白蛆）

  • 外观：白色巨型蛆虫状
  • 特性：皮糙肉厚，难以击杀
  • 危险等级：高（群居+高防御）

3.3 其他变异昆虫

  • 各类被感染的昆虫均有变异可能
  • 大小普遍增大数倍至数十倍
  • 保留原有昆虫特征但大幅强化

四、变异兽（变异兽）

变异兽是末日后被感染变异的动物，种类繁多，力量强大。

4.1 变异兽特征

  • 体型大幅增大
  • 具有超常的攻击性
  • 可能拥有特殊能力（酸液、毒气等）
  • 头部有魔晶
  • 部分变异兽的肉可食用且有强化效果

4.2 已知变异兽类型

  • 变异犬/狼：速度极快，成群行动
  • 变异猫科：潜伏和爆发力极强
  • 变异鼠群：数量庞大
  • 变异鸟类：空中威胁
  • 变异蛇类：毒性强化
  • 变异熊/大型猛兽：力量型怪物
  • 变异蜘蛛：织网和毒素能力
  • 变异蝎子：毒尾和甲壳

4.3 战兽

  • 部分变异兽可被职业者（召唤师等）驯服为战兽
  • 战兽与主人之间存在契约关系
  • 优秀战兽能极大增强主人战力

五、变异植物（变异植物）

5.1 概述

末日降临时，不仅是动物，植物也发生了恐怖的变异。变异植物极端危险，在末日后世界中，它们甚至能阻挡大部分兽潮入侵人类聚居地。

5.2 变异植物特征

  • 食性改变：从光合作用变为嗜血
  • 攻击性：主动捕食靠近的生物
  • 生长速度：极快
  • 体型：可长到极其巨大
  • 能力：
  • 藤蔓缠绕
  • 毒液/腐蚀液喷射
  • 根须攻击
  • 花粉/孢子毒气

5.3 变异植物与生态

  • 变异植物构成末日后世界的新生态系统
  • 它们与变异兽互相制衡
  • 部分变异植物区域成为人类禁区
  • 但同时它们也阻挡了部分怪物入侵人类基地

5.4 注意事项

  • 即使是高级进化者也不愿意轻易进入变异植物区域
  • 需要火焰、特殊药剂等手段才能有效对抗

六、地狱兽与高等怪物

6.1 地狱兽

  • 末日后期出现的超高等怪物
  • 具备恐怖的力量和防御
  • 通常体积极其庞大
  • 可能需要多支战队联合对抗
  • 掉落最高品质的魔晶

6.2 异形种

  • 来源不明的高级怪物
  • 形态多样，能力各异
  • 极度危险

6.3 远古种

  • 可能在末日前后就已存在的古代生物
  • 被末日力量唤醒或强化
  • 实力极其恐怖

一、游戏核心循环

探索世界 → 猎杀怪物 → 获取魔晶 → 转动轮盘(抽卡/抽奖)
    ↑                                        ↓
    │                                    获取奖励
    │                                        ↓
    └────────── 变强后挑战更难内容 ←──── 进化/装备/技能提升

二、核心系统设计建议

2.1 轮盘抽奖系统

设计要点:
- 多个等级轮盘分布在世界各地
- 消耗魔晶（货币）抽奖
- 随机奖励池（类似gacha）
- 稀有轮盘有使用限制/占领机制
- 彩色轮盘 = SSR/UR级奖励（职业解锁）

2.2 魔晶货币系统

击杀怪物 → 获得魔晶
         ↓
用途: 转轮盘 / 交易 / 锻造材料 / 强化装备
         ↓
不同颜色魔晶 = 不同价值层级
         ↓
高阶魔晶极难获取 → 驱动玩家挑战高难内容

2.3 进化者等级系统

玩家等级 = 星阶进化者
  一星 → 二星 → ... → 十星
  每星突破需要: 对应进化药剂
  进化药剂来源: 轮盘抽奖 / 高级制作 / 副本BOSS掉落

2.4 职业系统

分为两大分支:
  战斗职业 (战士/枪手/法师/召唤师/刺客...)
  辅助职业 (锻造师/药师/附魔师/厨师...)

获取方式: 彩色轮盘抽出职业证书
职业等级: 见习 → 初级 → 中级 → 高级 → 大师 → 宗师 → 传说
升级方式: 熟练度积累 + 进阶试炼任务

八、核心设计哲学

  1. 轮盘 = 核心驱动力：一切围绕"打怪→获得魔晶→转轮盘→变强"循环
  2. 随机性 = 重玩价值：轮盘的完全随机性带来每局不同的体验
  3. 职业多样性 = 玩法深度：战斗+辅助双职业体系提供丰富的Build空间
  4. 势力博弈 = 世界活力：动态的势力关系让世界有生命力
  5. 渐进式揭秘 = 叙事张力：从末日生存到天界真相的层层递进
